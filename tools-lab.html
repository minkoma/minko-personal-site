Five ways to present the toolkit

Same 23 tools, same five groups, read from the same list that is in js/content.js. Only the presentation changes. Nothing here is interactive beyond hover: this block presents a skill set, it does not claim a proficiency level, so there are no bars, percentages or star ratings anywhere.

Real brand vectors come from Simple Icons (CC0, single path, recoloured with a CSS mask). Eight tools are not in that set at all (CapCut, Final Cut Pro, iMovie, Keap, Sprout Social, Brandwatch, Later, Excel), so they show as outlined monogram chips. If one option wins, those eight get hand-drawn glyphs so the row reads evenly.

option 1

Logo wall

Flat grid, grouped, resting in one quiet ink tone so the wall reads as texture rather than 23 competing logos. Hover brings that one tool to its brand colour and lifts its name out of the fog. Closest to what is on the site now, and the safest to drop into the contact section.

option 2

Trays on a table

Five tilted trays, each with its group name on a sticky label, icons scattered inside at small random angles. Hovering a tray straightens it and lifts it off the table. This is the one that matches the paper-and-handwriting collage the rest of the site is built from.

option 3

Filmstrip

One strip per group, icons sitting in the frames between the sprocket holes, drifting slowly and in alternating directions. Hover anywhere on a strip stops it. Borrows the language of the film section, and holds any number of tools without getting taller.

option 4

Letterpress

Every tool pressed into the same paper in the same colour, no brand colours at all. The most restrained option, and the one that looks least like a badge collection. The cost is recognition: at a glance these read as shapes, not as logos you know.

option 5

Orbits

Five slow carousels, group name in the middle, tools circling it. Most memorable, most motion, and the furthest from the paper feel of the rest of the page. Hover stops a whole orbit; icons stay upright while the ring turns.
