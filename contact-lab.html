The contact rows, five ways

Same content every time: what Minko is open to, and how to reach her. What changes is which things look pressable, and what the colour means.

What is wrong with the live version

  1. One pill, four meanings. “Full-time” is a fact, “copy email” acts in place, “résumé ↗” opens another page of this site, “linkedin ↗” leaves for another site. All four are the same filled plum pill, so the shape tells you nothing.
  2. The outlined field chips look like filters. A rounded outline in the accent colour is button language. Nothing happens when you press them, which is a small dead end five times over.
  3. The real action is the quietest thing in the row. Writing to Minko is the point of the section, and the address is plain text with a thin underline, sitting next to a filled button that only copies it to the clipboard.
  4. Internal and external links are indistinguishable. Both carry ↗, though only one takes you off the site.
  5. Plum is spent everywhere, so it cannot mark anything. The eye has no way to find the one thing worth clicking.

The rule each option below follows, in one form or another:

A fact is never pill-shaped. One filled element per row, and it is the action that matters. An in-place action sits beside the thing it acts on and stays quiet. A link that leaves the site is underlined and carries ↗.

Option 1 · Plain facts, one call

the quietest

The “open to” row stops being chips and becomes a sentence, which is how you would say it out loud. The only filled button on the card writes to her; copying is a bordered afterthought, and the two links read as links.

Option 2 · A list of channels

this is what shipped

One line per channel: email, LinkedIn, résumé. Each value is the address itself, in ordinary text at normal weight with an underline, which is all a link needs. The only button left is "copy email", because copying is the one thing in the row that is not navigation. Facts lose their outlines entirely and the one piece of state keeps a soft mint badge.
